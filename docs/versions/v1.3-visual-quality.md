# v1.3 Visual Quality

v1.3 的目标是提升最终视频的观感、字幕可读性、封面质量和自动质检能力。到这个阶段，视频应该从“能跑通”变成“可以稳定发布前审核”。

## 核心目标

- Remotion 模板更像短视频工具科普，而不是 PPT。
- 字幕和画面重点字幕分层明确。
- 封面能自动生成多个可用方案。
- 生成后能自动发现明显质量问题。

## 必须实现

1. Remotion 模板升级：
   - 工具定位型开场。
   - 核心功能解释。
   - 工作流流程图。
   - 适合场景。
   - 关键差异。
   - 结尾总结。
2. 视觉表达要求：
   - 1080x1920 竖屏优先。
   - 信息密度高但不拥挤。
   - 画面文字完整展示，不使用省略号截断。
   - 不显示内部模板名。
   - 不显示 `unknown`、`待补充`。
3. 字幕增强：
   - 口播字幕和画面重点字幕分离。
   - 按语义和口播节奏断句。
   - 每屏最多 2 行。
   - 重点词可高亮。
   - 字幕停留时间满足阅读。
4. 封面系统：
   - 生成 2-3 个封面标题方案。
   - 自动选择默认封面。
   - 输出 `cover.png`。
   - 输出封面标题和副标题到 `creative.json` 或 `cover.json`。
5. 自动质检：
   - 首帧非黑屏。
   - 开头 1 秒黑帧检测。
   - 音频存在且不是静音或测试音。
   - 字幕末尾与视频时长一致。
   - 画面文字禁用省略号、占位词和模板标签。
   - 输出 `validation.json`。

## 不做

- 不做复杂在线设计编辑器。
- 不做用户手动拖拽排版。
- 不做品牌账号水印。
- 不做固定账号 Logo 或角标。

## 验收标准

- `final.mp4` 打开首帧可见。
- 视频中无内部模板标签。
- 主要画面文案没有省略号截断。
- `voice.mp3` 是真实 TTS。
- `captions.srt` 与旁白基本同步。
- `cover.png` 可直接作为短视频封面候选。

## 当前实现

- 字幕按标点、语义连接词和长度共同切分，单条优先控制在 8-18 个中文字附近，最长不超过 22 个中文字。
- 渲染层会把口播字幕和画面重点文字分开：字幕来自 `captions.json`，画面重点来自 scene 的 `bullets`、`visualFocus` 和 `onScreenFocus`。
- 可见文字质检会拦截省略号、`unknown`、`待补充`、内部模板名和画面链接。
- `validateOutput` 会检查首帧、开头黑帧、视频规格、音频采样率和时长范围。
- 封面生成会输出 `cover.png` 和 `cover.json`，`cover.json` 包含默认封面方案和 2 个备用标题方案。
- 缺官网截图时使用生成式封面底图，不添加账号水印、固定角标或无关品牌 Logo。

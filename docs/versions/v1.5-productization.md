# v1.5 Productization

v1.5 的目标是把稳定的 CLI 流水线升级为可持续批量生产的工具。这个阶段才开始引入任务管理、审核流和产品化界面。

## 核心目标

- 支持批量生成。
- 支持人工审核和局部重生成。
- 支持项目历史和产物管理。
- 支持发布前素材、脚本、字幕、封面检查。

## 必须实现

1. 任务系统：
   - 创建生成任务。
   - 查看任务状态。
   - 失败重试。
   - 记录生成日志。
2. 项目产物管理：
   - 输入信息。
   - research。
   - creative。
   - script。
   - assets。
   - voice。
   - captions。
   - scenes。
   - final video。
   - cover。
3. 审核流：
   - 查看脚本。
   - 查看素材。
   - 查看字幕。
   - 查看封面。
   - 只重生成某一段或某一类产物。
4. 批量能力：
   - 批量导入工具列表。
   - 批量生成草稿。
   - 批量导出视频和封面。
5. 发布辅助：
   - 标题候选。
   - 简介文案。
   - 标签候选。
   - 平台适配建议。

## 不做

- 不在内容质量稳定前提前做复杂后台。
- 不做自动发布到平台，除非后续明确需要。
- 不把审核流做成专业剪辑软件。
- 不支持多人权限系统，除非真实使用场景需要。

## 验收标准

- 用户可以连续生成多个工具视频。
- 每个任务都能追踪输入、状态、错误和产物。
- 用户可以重生成脚本、配音、字幕、封面或单个 scene。
- 批量导出的视频目录结构清晰。
- 产品界面不破坏 CLI 主流程，CLI 仍可独立运行。

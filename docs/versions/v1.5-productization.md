# v1.5 Optional Productization

v1.5 当前暂缓。现阶段 ToolReel 主要由个人使用，直接通过 Codex 驱动 CLI、查看中间产物和继续迭代即可，不需要过早建设后台、任务系统或审核界面。

只有当 CLI + Codex 工作流明显不够用时，才重新启动本版本。

## 重新启动条件

满足以下任意条件时，再考虑 v1.5：

- 每天需要批量生成大量视频，手动输入 CLI 已经影响效率。
- 需要长期保存、搜索和复用大量历史项目。
- 需要在界面里审核脚本、素材、字幕、封面并局部重生成。
- 需要多人协作或明确的任务状态管理。

## 可选目标

- 支持批量生成。
- 支持人工审核和局部重生成。
- 支持项目历史和产物管理。
- 支持发布前素材、脚本、字幕、封面检查。

## 可选实现

1. 任务系统：
   - 创建生成任务。
   - 查看任务状态。
   - 失败重试。
   - 记录生成日志。
2. 项目产物管理：
   - 输入信息。
   - research。
   - creative。
   - script。
   - assets。
   - voice。
   - captions。
   - scenes。
   - final video。
   - cover。
3. 审核流：
   - 查看脚本。
   - 查看素材。
   - 查看字幕。
   - 查看封面。
   - 只重生成某一段或某一类产物。
4. 批量能力：
   - 批量导入工具列表。
   - 批量生成草稿。
   - 批量导出视频和封面。
5. 发布辅助：
   - 标题候选。
   - 简介文案。
   - 标签候选。
   - 平台适配建议。

## 不做

- 不在内容质量稳定前提前做复杂后台。
- 不做自动发布到平台，除非后续明确需要。
- 不把审核流做成专业剪辑软件。
- 不支持多人权限系统，除非真实使用场景需要。

## 验收标准

- 用户可以连续生成多个工具视频。
- 每个任务都能追踪输入、状态、错误和产物。
- 用户可以重生成脚本、配音、字幕、封面或单个 scene。
- 批量导出的视频目录结构清晰。
- 产品界面不破坏 CLI 主流程，CLI 仍可独立运行。
